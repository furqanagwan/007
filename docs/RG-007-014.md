# RG-007-014: Quantum of Solace lists its title update

`quantumofsolace.toml` lists title update 2 (`[[title_update]]`: media
`06DD88A0`, base version 7, content ID
`B59A1F29F4FB82AB35DC7AEC8975F83F620A8290`, 2,420 KB, uploaded 2012-06-18;
Xbox Unity TitleUpdateID 22386). The SDK's guide (rexglue-sdk#153) shows it in
Games & Apps > Title Updates: optional, downloaded from Xbox Unity and turned
on or off there. No source says what it changes, so there is no changelog.

Not done: the update's own executable. A manifest `[[title_update]]` builds
`quantumofsolace_tu2.exe` from the package, but it needs its own config: with
none, it runs until "Call to invalid or unregistered function at guest
address 0x821C1C20", one of the entries `quantumofsolace.toml` adds for the
original. Until that config exists, builds from this repository have no
update executable, and the guide shows the update as Not in Build.

Validated 2026-10-01 (NVIDIA RTX 5080 Laptop GPU, GDK Release, a local
manifest with the update build): the guide downloaded the update from Xbox
Unity and installed it, and turning it on started `quantumofsolace_tu2.exe`.
