# RG-007-012: The games' marketplace add-ons

SDK RG-GDK-050 ([rexglue-sdk#145](https://github.com/furqanagwan/rexglue-sdk/issues/145))
makes the guide's Games & Apps > Manage Game list every add-on a title had in
the Xbox 360 marketplace, with its banner and description, and install it from
a package on this PC. A title lists its add-ons as `[[dlc]]` entries; the build
fetches the rest from the marketplace catalogue (nothing fetched is committed).

Found with `rexglue dlc-find <title ID>` against the en-GB catalogue
(`catalog.xboxlive.com`), 2026-10-01, and title updates against Xbox Unity
(`TitleUpdateInfo.php`):

| Game | Add-on | Marketplace ID | Title updates |
| --- | --- | --- | --- |
| 007 Legends (`415608D8`) | SKYFALL Content Pack (free) | `D4C83E1F-243B-4A68-AD70-ABF3C0FBF372` | none exist |
| | Eve Character Skin | `A492C3E9-105C-41DD-9CD8-4977A615655A` | |
| | Patrice Character Skin | `30621358-F254-48C1-B607-B6AA7DAACC33` | |
| Quantum of Solace (`415607FF`) | The Camille Map Pack (four multiplayer maps) | `00000000-0000-400C-80CF-0001415607FF` | version 2 for this disc (media `06DD88A0`, TitleUpdateID 22386) |
| Blood Stone (`4156081F`) | none | | version 1 (TitleUpdateID 21621) |

- 007 Legends has no title update, so none of its add-ons can need one.
- Legends' own cheat code `l3g3nds` (Skyfall Pack, [RG-007-011](RG-007-011.md))
  unlocks the Skyfall mission, Eve and Patrice: the content is on the disc,
  and the add-ons are likely unlocks for it. Not checked against the
  packages.
- Whether The Camille Map Pack needs Quantum of Solace's title update 2 is not
  established. The update holds `default.xexp`, `default_mp.xexp` and
  `patch_mp.ff`, so it patches the multiplayer executable, but no source says
  the maps need it. `requires_title_update` is left unset.

Configs: `configs/legends.toml` (three entries) and
`configs/quantumofsolace.toml` (one). Blood Stone needs none.

Validated: 007 Legends at 3840 x 2160 lists the three add-ons with Install, the
007 Legends banner and each description; Quantum of Solace builds with its
catalogue. Installing a real package is not tested: no add-on packages here.
