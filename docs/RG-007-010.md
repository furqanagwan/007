# RG-007-010: Cheats from the Aurora trainer pack

Source: [StonedModder/Aurora-JTAG-RGH-Trainer-Pack-Repository](https://github.com/StonedModder/Aurora-JTAG-RGH-Trainer-Pack-Repository/tree/main/Aurora/user/Trainers),
which has trainers for 415607FF (Quantum of Solace) and 415608D8 (007
Legends), none for Blood Stone (4156081F). Both are XYZEngine trainers
(`(XYZGEN)Trainer.xex`, by Boogieman), reviewed 2026-10-01.

## How they were read

The trainers are Xbox 360 modules Aurora loads beside the game. They patch the
game's PowerPC code in memory, which a recompiled game no longer runs, so they
cannot be used as they are. Each was decrypted (devkit key) and decompressed
with the SDK's LZX decoder, and its cheat table disassembled: every cheat is
an address, the original instruction and the one it writes. Every original
word was checked against our XEX. Nothing from the trainers is shipped; the
configs hold only the addresses and instructions, as Canary game patches do.

Each cheat is a switchable `[[patch]]` with `category = "cheat"` (SDK
RG-GDK-041), listed in the Xbox guide's Settings > Cheats, off by default,
turned on and off while playing and saved with the title's settings.

## Quantum of Solace (`configs/quantumofsolace.toml`)

| Trainer cheat | Patch | Change |
| --- | --- | --- |
| Inf & Max Ammo | Infinite Ammo | `82161A38` `subf r9,r11,r10` -> `ori r9,r10,999` |
| Inf & Max grenades | Infinite Grenades | `821665B0` `subf r11,r9,r11` -> `ori r11,r11,999` |
| God | God Mode | `82252BCC` `stw r30,380(r31)` -> `nop`; before `82233698` (`stw r11,380(r31)`), r11 = 30000 when lr = `82233674` |
| I-Kill | One-Hit Kills | before `82233698`, r11 = 0 when lr = `82233484` |

God and I-Kill are a detour in the trainer: it checks the return address of
the last call to tell the protected entity's path from the others'. They are
`[[patch.set]]` register writes keyed on `lr`, which the recompiled code
keeps as the console does.

## Validation

- Codegen lists every cheat as switchable; the generated code holds both
  instruction versions, and QoS's register sets sit directly before the
  health store, as the trainer's detour does.
- Both titles (GDK Release, 2026-10-01): Settings > Cheats lists the cheats;
  toggling one updates the checkbox and saves `code_patch_states`.
- Not yet checked in play: the effect of each cheat in a mission. Like the
  trainers, they assume the disc versions these configs target.
