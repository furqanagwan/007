# RG-007-002: Quantum of Solace constant-return leaf entries

Tested XEX identity: title `415607FF`, media `06DD88A0`, SHA-256
`a96f4f651cc0937e51aa2f81245b48ba08d71de1b8bef0e33bc2b2bca29caa42`.
The entry list in `configs/quantumofsolace.toml` applies only to this build.

After RG-007-001, two NVIDIA D3D12 boots both stopped at an unregistered
indirect call to `0x821C1C20`. That address is a two-instruction PPC leaf body
(`li r3,8; blr`) inside the `sub_821C1B90` jump-table region. A single-entry
diagnostic hint registered it, but two reruns then stopped at `0x821C1C38`,
another independent `li r3,12; blr` leaf body in the same region.

The configuration now lists all 19 distinct eight-byte constant-return leaf
bodies from `0x821C1BA8` through `0x821C1C38`. Code generation registered
each entry, preserved `switch (ctx.r3.u32)` for `sub_821C1B90`, and removed
the previous unresolved direct-branch warning for `0x821C1BF8`. No PPC bytes
or generated game sources were changed in Git. The private Release title build
succeeded with SDK codegen commit `95e7f92`.

Two fresh NVIDIA D3D12 runs with separate disposable user roots passed the
`0x821C1C20` and `0x821C1C38` failures, then both exited `0xC0000409` at a
new invalid/unregistered call to `0x82462590`. The private executable SHA-256
was `fb26b466936fa3f86d12044bf3df5544f2cdc9f354fa5a4a1ceaf1762c30239f`.
Private evidence: `Quantum of Solace/baseline/rg007002-all-boot-{1,2}/run.json`
and title logs `quantumofsolace_019.log`/`quantumofsolace_020.log`. The next
failure is tracked as [RG-007-003](https://github.com/furqanagwan/007/issues/4).
Initial boot still fails; rendering, gameplay, saves and GDK deployment are
unvalidated. AMD and Intel graphics remain untested.
