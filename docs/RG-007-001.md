# RG-007-001: Quantum of Solace guest entry at 0x8211E798

Tested title: ID `415607FF`, media `06DD88A0`, XEX SHA-256
`a96f4f651cc0937e51aa2f81245b48ba08d71de1b8bef0e33bc2b2bca29caa42`.
No title update was applied. The entry hint is scoped to this exact source
build; a different XEX requires renewed validation.

The pre-fix generated registry contained entries at `0x8211E750` and
`0x8211E7BC`, but not `0x8211E798`. The private title log from two NVIDIA
D3D12 runs reported an indirect call to `0x8211E798`, then a fatal invalid or
unregistered function. The codegen hint in `configs/quantumofsolace.toml`
causes a valid function at that address to be generated and registered. Its
decoded entry bounds-checks an argument, returns an error on failure, and on
success reaches a shared virtual-call tail at `0x8211E7BC`. The hint does not
replace instructions or suppress the call.

The private manifest includes `../../configs/quantumofsolace.toml`. Generation
used the `RG-FIX-001` SDK codegen executable rebuilt from commit `95e7f92`.
Before that rebuild, a stale codegen executable restored the old jump-table
bug and two diagnostic runs exited `0xC000001D`; those runs are **not** evidence
against this title hint. The corrected output selects guest `r3` in
`sub_821C1B90` and registers `sub_8211E798`. The private Release title build
succeeded in a Visual Studio x64 developer shell.

Two corrected NVIDIA D3D12 boot runs used the same XEX and executable SHA-256
`f864ba7cbb33ec25d2ee13daff01cd305be8323fa09d415dd9b70fc72c6817c3`
with separate disposable user roots. Both passed the former `0x8211E798`
failure and exited `0xC0000409`; their title logs report a **new** fatal
unregistered call at `0x821C1C20`, tracked as
[RG-007-002](https://github.com/furqanagwan/007/issues/2). Private evidence is in
`Quantum of Solace/baseline/rg007001-corrected-boot-{1,2}/run.json` and title
logs `quantumofsolace_015.log`/`quantumofsolace_016.log`. The game still fails
initial boot. Rendering, gameplay, saves and GDK deployment are unvalidated.
Only NVIDIA was tested locally; AMD and Intel graphics remain untested.
