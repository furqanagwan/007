# RG-007-003: Quantum of Solace guest entries near 0x82462590

Tested XEX: title `415607FF`, media `06DD88A0`, SHA-256
`a96f4f651cc0937e51aa2f81245b48ba08d71de1b8bef0e33bc2b2bca29caa42`.
These entry hints apply only to this exact build.

After RG-007-002, two NVIDIA D3D12 runs both stopped at an unregistered
indirect call to `0x82462590`. A title hint made codegen emit and register its
valid PPC leaf body, which reads a float from a guest object and returns.
Two reruns passed that address and stopped at `0x82462668`, another valid leaf
body nearby. A second hint registers its original guest body, which follows
guest pointers and returns an address. Neither hint bypasses an instruction.

Regeneration with SDK codegen commit `95e7f92` and private Release build both
succeeded. Two final NVIDIA D3D12 runs with separate disposable user roots
passed both former addresses, then exited `0xC0000409` at a distinct invalid
call to `0x824E1710`. Their executable SHA-256 was
`e3e308aa81fb125f299f89b78299ca8b400621d532c6da73100359c3cc7b827d`.
Private evidence: `Quantum of Solace/baseline/rg007003-two-boot-{1,2}/run.json`
and title logs `quantumofsolace_023.log`/`quantumofsolace_024.log`. The next
failure is tracked as [RG-007-004](https://github.com/furqanagwan/007/issues/6).

Initial boot still fails. Rendering, gameplay, saves and GDK deployment are
unvalidated. AMD and Intel graphics remain untested.
