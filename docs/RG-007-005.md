# RG-007-005: Quantum of Solace interactive validation

Issue: [#16](https://github.com/furqanagwan/007/issues/16). This follows
the initial missing-entry work documented in [RG-007-004](RG-007-004.md).

Tested title: Xbox 360 title `415607FF`, media `06DD88A0`, private XEX
SHA-256 `a96f4f651cc0937e51aa2f81245b48ba08d71de1b8bef0e33bc2b2bca29caa42`.
The tracked title configuration is `configs/quantumofsolace.toml`; private
game data, generated C++, saves and screenshots remain outside Git.

Current local validation hardware is an NVIDIA RTX 5080 Laptop GPU with
the D3D12 Xenos plugin. AMD and Intel graphics are unavailable and are not
acceptance gates for this game-specific work. GDK validation belongs to
the SDK migration issues.

The preceding work verified that a title window displayed changing outdoor
3D views for over two minutes without a fatal or missing-function log. The
next checkpoint is a reproducible route from launch to interactive menu or
gameplay. Record the exact executable and runtime hashes, private window
captures, input method, elapsed time, runtime log and resulting save state.
Only then assess rendering and gameplay against a suitable reference.

An initial live run from 13:46 local time displayed changing 3D views and
in-game interface elements, including a mission objective overlay. Private
window crops `rg007005-window-{1,2,3}.png`,
`rg007005-window-after-start.png` and
`rg007005-window-start-held.png` record that observation. The input result
is inconclusive: the host XInput device in slot 0 reported large nonzero
left and right stick values during the run, and the camera moved without
controlled test input. A Return and an X key press, both mapped to Start by
the SDK's keyboard driver, produced no unambiguous pause or menu transition.
The title process was stopped after this observation. Log:
`quantumofsolace_060.log`.

A second run started with the observed USB controller VID/PID
`0x0B05/0x1C92` excluded using SDL's device-ignore hints, while retaining
the SDK keyboard driver. The title log `quantumofsolace_061.log` confirms
SDL input initialized without a controller-added event. This isolates the
keyboard test from the active physical sticks; interaction results are still
pending.

Open checks:

- Reach an interactive title or gameplay screen on a fresh user-data root.
- Confirm controller or keyboard input changes game state, with before/after
  captures and logs.
- Exercise a short gameplay sequence and inspect visible rendering defects.
- Verify a save, restart and load using disposable private user data.
- Track any distinct SDK or title fault in its own issue and branch, then
  repeat this checkpoint after that fix is merged.
