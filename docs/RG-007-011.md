# RG-007-011: Mods, and 007 Legends' own cheat codes

SDK RG-GDK-043 ([rexglue-sdk#132](https://github.com/furqanagwan/rexglue-sdk/issues/132))
splits the guide's cheats in two:

- **Settings > Mods**: the trainer patches from [RG-007-010](RG-007-010.md),
  now `category = "mod"` in `configs/quantumofsolace.toml` and
  `configs/legends.toml`. Names are unchanged, so saved on/off choices
  (`code_patch_states`) carry over.
- **Settings > Cheats**: the cheats the developers built in, which a player
  types in at the game's menu. Nothing is patched; the guide lists each code,
  what it unlocks and where to enter it.

## 007 Legends (`configs/legends.toml`)

Typed in at Extras > Cheat Codes; case sensitive.

| Name | Code | Unlocks |
| --- | --- | --- |
| James Bond (Jacket) | `f1n3att1r3` | Bond in his jacket, split-screen |
| James Bond (Astronaut) | `astr0b0y` | Bond in his astronaut suit, split-screen |
| 007 Pack | `g3tb0nd` | Walther PPK (single-player and multiplayer), Fast Switch gadget (multiplayer) |
| Moonraker Pack | `m00nlas3r` | Moonraker Laser Mk2 (multiplayer) |
| Goldfinger Pack | `au43v3r` | Goldfinger (Fort Knox) and Pussy Galore (Pilot) (multiplayer) |
| Nemesis Pack | `v00d00f1sh` | Jaws (Astronaut) and Baron Samedi (Skeleton) (multiplayer) |
| Stealth Pack | `qbranch3d` | Long Reach and Acute Hearing gadgets (multiplayer) |
| Skyfall Pack | `l3g3nds` | Skyfall mission, Eve, Patrice, Kowloon T-100, Tactical FSR (multiplayer) |

Sources, read 2026-10-01, which agree on every code:
[GameRevolution](https://www.gamerevolution.com/guides/57159-007-legends-xbox360-cheats),
[Cheat Code Central](https://www.cheatcc.com/articles/007-legends-cheats-codes-cheat-codes-walkthrough-guide-faq-unlockables-for-xbox-360-xbox360/).
IGN's page could not be fetched. The codes are not stored as text in the
game's executable or files, so they were not checked against the game, and
entering them in the recompiled game has not been tried.

Quantum of Solace and Blood Stone have no cheat codes listed, so their Cheats
page says so.

## Validation

- 007 Legends (GDK Release, 3840 x 2160, 2026-10-01): Settings > Mods lists
  the six trainer mods; Settings > Cheats lists the eight codes, and moving
  between them shows each code, what it unlocks and where to enter it.
