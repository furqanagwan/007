# RG-007-008: optional 60 FPS build of Quantum of Solace

Issue: [#22](https://github.com/furqanagwan/007/issues/22).
Shared SDK work: [rexglue-sdk#111](https://github.com/furqanagwan/rexglue-sdk/issues/111),
[PR #112](https://github.com/furqanagwan/rexglue-sdk/pull/112) (codegen patches).

## The patch

Xenia Canary's [game-patches](https://github.com/xenia-canary/game-patches)
entry `415607FF - 007 Quantum of Solace.patch.toml`, "Unlock FPS" by Sowa_95,
for `default.xex` (Canary module hash `A29428CB1432DD9E`, media `06DD88A0`),
copied unchanged into `configs/quantumofsolace.toml`. The owner plays with it
on in Xenia Edge.

| Address | Write | What it changes |
| --- | --- | --- |
| `0x8229B808` | `nop` | `lwz r11,21268(r7)` in `sub_8229B7C0`, the frame-timing setup |
| `0x8229B86C` | `nop` | `lfs f0,-9124(r10)` in the same function |
| `0x820F2283` | `0x01` | Low byte of `li r11,1` at `0x820F2280`, the presentation interval (`0x00` unlimited, `0x01` 60 FPS, `0x02` 30 FPS). `0x01` is the original value. |

All three are in code, so the SDK compiles them in. Canary warns: "FPS higher
than 30 can cause softlocks in certain missions."

## How to build it

`configs/quantumofsolace.toml` ships the patch with `enabled = false`; the
default build is unchanged. `configs/quantumofsolace-60fps.toml` includes it
and switches the patch on. Use it in the manifest's `includes` in place of
`quantumofsolace.toml`, then regenerate. Codegen logs
`Applied patch "Unlock FPS" (3 writes)` and the title logs
`Guest code patches compiled in: Unlock FPS` at startup.

## Result, 2026-09-29

SDK `175d087`, GDK Release, NVIDIA RTX 5080 Laptop GPU, disposable user data.
Both patched instructions are `nop` in the generated C++. A 138 s session
loaded the save, wrote profile settings and exited with code 0; the log has no
errors and no warnings beyond missing language packs. The owner reports it
played fine.

Not checked: the missions where Canary reports softlocks. Broader gameplay
remains in [#16](https://github.com/furqanagwan/007/issues/16).
